# Styled Components no ReactJS

Projeto de estudo demonstrando o uso de **Styled Components** para estilização de componentes React com CSS-in-JS.

## O que é demonstrado

- Criação de componentes estilizados com `styled-components`
- Uso de props para estilização dinâmica
- Organização de estilos por componente
- Tema global com `ThemeProvider`

## Tecnologias

- **React** — biblioteca de UI
- **Styled Components** — CSS-in-JS

## Como executar

```bash
npm install
npm start
```

Acesse `http://localhost:3000`
